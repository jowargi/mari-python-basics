# Домашнее задание: Функции в Python

## Задание 1. Базовые функции (разминка)

Напишите функцию `say_bye(name)`, которая выводит на экран прощание с человеком, например: `"Пока, Аня!"`. Вызовите её для трёх разных имён.

## Задание 2. Функция с параметрами по умолчанию

Напишите функцию `order_pizza(size="средняя", topping="сыр")`, которая печатает сообщение вида:
`"Заказ: пицца {size}, топпинг: {topping}"`.

Проверьте её работу в трёх вариантах:

- без аргументов;
- только с размером;
- с обоими аргументами (в том числе через именованные параметры в другом порядке).

## Задание 3. Возврат значения

Напишите функцию `get_min(a, b)`, которая **возвращает** (через `return`) наименьшее из двух чисел. Сохраните результат в переменную и выведите её на экран. Проверьте на нескольких наборах чисел.

## Задание 4. Практика с `*args`

Напишите функцию `get_average(*numbers)`, которая возвращает среднее арифметическое всех переданных чисел. Если чисел не передано — верните `0`.

Проверьте:

- `get_average()` → `0`
- `get_average(10)` → `10.0`
- `get_average(1, 2, 3, 4, 5)` → `3.0`
